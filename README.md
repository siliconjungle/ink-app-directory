# Ink App Directory

Apps for [Ink OS](https://github.com/siliconjungle/ink-os-platform). Each app has its own source repository and installation instructions.

## Included with Ink OS

- [Finder](https://github.com/siliconjungle/ink-app-finder) — Browse live Ink records, organize collections and saved views, import files and create records with typed properties.
- [Preview](https://github.com/siliconjungle/ink-app-preview) — Read text, images, audio and video, and download other files in an isolated Ink app.
- [Ink Environment](https://github.com/siliconjungle/ink-app-ink-environment) — Edit and compile Ink programs, select functions, provide exact JSON inputs, run programs and inspect diagnostics, timings and generated code.

## More apps

- [Chat Room](https://github.com/siliconjungle/ink-app-chat-room) — Chat with ordered messages, immediate pending sends, paginated history and retry-safe delivery.
- [Color Picker](https://github.com/siliconjungle/ink-app-color-picker) — Sample screen colours, copy HEX/RGB/HSL values and keep shared swatches.
- [Curves](https://github.com/siliconjungle/ink-app-curves) — Create named game-balancing curves with draggable control points, interpolation, numeric previews and JSON exports.
- [Image Converter](https://github.com/siliconjungle/ink-app-image-converter) — Convert images to PNG, JPEG or WebP with resizing, quality controls, batch processing and shared history.
- [Ink Tables](https://github.com/siliconjungle/ink-app-tables) — Edit typed, queryable tables for game balancing and configuration, with stable row/column keys and CSV/TSV import.
- [Level Editor](https://github.com/siliconjungle/ink-app-level-editor) — Author collaborative orthogonal tile maps with layers, typed properties, stamps, painting tools and personal undo.
- [Links](https://github.com/siliconjungle/ink-app-links) — Keep a shared shelf of URLs with metadata previews, ordering, search and undo.
- [Moodboard](https://github.com/siliconjungle/ink-app-moodboard) — Collect images on shared masonry boards with drag ordering, immediate upload previews and board recovery.
- [Music](https://github.com/siliconjungle/ink-app-music) — Play managed audio files with a shared library, queue, shuffle, repeat and system media controls.
- [Palette Analysis](https://github.com/siliconjungle/ink-app-palette-analysis) — Inspect image palettes through colour-space charts, brightness and saturation comparisons, nearest-colour fields and dithering reports.
- [Pixelate](https://github.com/siliconjungle/ink-app-pixelate) — Turn images and GIF animations into pixel artwork using structure or K-centroid reconstruction, shared palettes and sequence-consistent settings.
- [Polls](https://github.com/siliconjungle/ink-app-polls) — Create shared polls, vote once per Ink account, inspect live results and export CSV.
- [Spreadsheet](https://github.com/siliconjungle/ink-app-spreadsheet) — Work with collaborative spreadsheets, formulas, cell formatting, personal sorting/filtering and CSV import/export.
- [Sprite Splitter](https://github.com/siliconjungle/ink-app-sprite-splitter) — Slice grid sprite sheets, select and preview frames, trim transparent borders and export PNG frames or ZIP packs.
- [Text Editor](https://github.com/siliconjungle/ink-app-text-editor) — Edit plain text files with shared drafts, find, line numbers, and revision-checked Save and Save As.
- [Video Call](https://github.com/siliconjungle/ink-app-video-call) — Make a two-person audio/video call using native WebRTC and ephemeral Ink signaling.
- [Workflows](https://github.com/siliconjungle/ink-app-workflows) — Connect app commands into shared workflows with declared inputs, step outputs, previews and durable run history.
